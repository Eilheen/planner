# Планировщик

Задачник и планировщик на день и неделю. Работает полностью в браузере: без сервера, без регистрации. Задачи хранятся в `localStorage`.

## Что умеет

**День**
- «Первый шаг»: одно дело, с которого стоит начать. Кнопки «Начать», «Готово», «Другое», таймер, пока дело в работе
- Порядок дел: сначала обязательное, потом важное, внутри — по времени
- Два вида: «Главное» (список) и «По часам» (шкала с линией «сейчас» и свободными окнами). Нажатие на пустое место шкалы создаёт задачу на это время
- Перегруз: пересечения по времени или нагрузка выше лимита (4–10 ч, меняется в меню)
- «Упростить день»: всё, кроме обязательного, переносится на завтра, можно отменить
- Напоминание о просроченных задачах и перенос на сегодня в одно нажатие
- Свайп влево/вправо на телефоне — соседний день

**Неделя**
- 7 колонок с прогрессом по дням, перетаскивание задач между днями и внутри дня (на телефоне — долгим нажатием)
- Заметки на неделю, перенос невыполненного на следующую неделю

**Задачи (задачник)**
- Все задачи разом: просроченные, входящие без даты, сегодня, завтра, дальше
- Поиск, фильтр по категориям, быстрый перенос на другую дату

**Быстрый ввод**: `Созвон 14:00 1ч #работа ! завтра`
- время `14:00`, `9.30`, диапазон `9:00-10:30`
- длительность `30м`, `45 мин`, `1.5ч`
- категория `#работа #учеба #личное #спорт #другое` (можно коротко: `#раб`)
- `!` — обязательно, `?` — если успею
- дата: `сегодня`, `завтра`, `послезавтра`, `пн`…`вс`, `в пятницу`

**Горячие клавиши** (работают и в русской раскладке): `N` — новая задача, `/` — быстрый ввод, `←` `→` — листать, `T` — сегодня, `1` `2` `3` — разделы, `⌘/Ctrl + Enter` — сохранить задачу.

**Ещё**: светлая, тёмная и системная тема; экспорт и импорт в JSON; отмена удаления и массовых действий; можно установить на телефон как приложение («На экран „Домой“»). Задачи из прошлой версии планировщика переносятся автоматически.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, готовый сайт будет в папке `dist/`.

## Публикация на GitHub Pages

1. Создай пустой репозиторий на GitHub и залей проект:

```bash
git init
git add .
git commit -m "Планировщик"
git branch -M main
git remote add origin https://github.com/<ник>/<репозиторий>.git
git push -u origin main
```

2. В репозитории открой **Settings → Pages** и в поле **Source** выбери **GitHub Actions**.
3. Через пару минут сайт будет доступен по адресу `https://<ник>.github.io/<репозиторий>/`. Каждый пуш в `main` обновляет его автоматически.
